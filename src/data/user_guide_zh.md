# Aether 使用指南

这份指南只回答一件事：第一次打开 Aether，怎样最快把它用起来。

## 先知道 Aether 是什么

Aether 主要有三层能力：

- `语音输入`：把说话变成文字
- `语音控制`：把说话变成点击、滚动、拖拽等操作
- `头控指针`：用兼容耳机的头部姿态控制光标

第一次使用，建议顺序固定为：

1. 先把权限补齐
2. 先试 `语音输入`
3. 再试 `语音控制`
4. 最后再开 `头控指针`

## 开始前

先确认：

- Aether 已安装在 `/Applications/Aether.app`
- `辅助功能`、`麦克风`、`语音识别` 已授权
- 如果要用头控，兼容耳机已连接到当前 Mac

打开 App 后，先看 `总览` 页顶部的 `准备情况`。  
它会直接显示现在缺的是权限、麦克风设备，还是别的前置条件。

## 第一次上手

### 1. 先把准备情况补齐

在 `总览` 页确认这四项都已经就绪：

- `辅助功能`
- `麦克风`
- `语音识别`
- 至少一个可用麦克风设备

如果某一项没完成，直接点页面里的按钮处理。

### 2. 先选一种说话方式

在 `总览` 页的 `语音基础` 里，你会看到三种唤起方式：

- `按住说话`
  最稳妥，最适合第一次使用。
- `唤醒词`
  先说唤醒词，再继续讲话。
- `免提`
  持续待命，最方便，但更依赖安静环境。

如果你不确定，先用 `按住说话`。

### 3. 先试语音输入

先不要急着用语音控制。  
第一次只要确认一件事：你说话时，输入框里能不能稳定出字。

最简单的测试方式：

1. 打开任意一个输入框
2. 用你选好的方式唤起语音
3. 直接说一句短话

如果这一步稳定了，再继续。

### 4. 再试语音控制

语音控制适合在不方便用手时执行操作。第一次只建议试简单动作：

| 功能 | 示例 |
| :--- | :--- |
| 点击 | `点击` / `click` |
| 双击 | `双击` / `double click` |
| 右键 | `右键` / `right click` |
| 向上滚动 | `向上` / `scroll up` |
| 向下滚动 | `向下` / `scroll down` |
| 开始拖拽 | `拖` / `drag` |
| 放下 | `放` / `drop` |
| 撤销 | `撤销` / `undo` |
| 重新校准 | `校准` / `recenter` |

如果你想看当前 App 还支持什么命令，可以打开：

- `应用快捷键` 页面
- 菜单栏里的 `快捷键面板`

### 5. 最后再开头控指针

头控指针更适合放在最后启用，因为它对姿态、耳机和当前环境更敏感。

基本步骤：

1. 连接兼容耳机
2. 在 `总览` 页打开 `头控指针`
3. 需要时再打开 `显示姿态引导`

如果光标总是偏一边，或者你换了坐姿、换了屏幕位置，就重新 `校准` 一次。

如果头控已经开了但没有反应，优先检查：

- 耳机是不是真的连在当前这台 Mac 上
- 耳机是否支持头部姿态
- `辅助功能` 是否已授权

## 几个常用页面

### `语音词库`

这里主要用来调整：

- 唤醒词
- 命令前缀
- 输入前缀
- 各语言下的命令说法

如果你经常说某个词，但 Aether 老是识别不到，先来这里改。

### `应用快捷键`

这里会显示当前前台应用能识别到的快捷键和常用控制项。  
浏览器、编辑器、终端，以及菜单项比较完整的原生 App，通常会比较有用。

### `语音统计`

这里可以看语音输入、语音控制的历史和统计。  
普通用户不需要天天打开，只有在排查“为什么经常失败”时才更有价值。

### `头部动作`

这里适合已经开始用头控的人。  
你可以在这里调整热区规则、点头/摇头行为，以及查看调试和历史记录。

### `About`

这里负责：

- 激活
- 试用
- 设备管理
- 更新通道切换
- 手动检查更新

如果你找不到更新入口，先去这里看。

## 日常建议

- 第一次先用 `按住说话`
- 先把 `语音输入` 用顺，再开 `语音控制`
- `免提` 最方便，但最依赖环境安静
- 命令不顺手时，先调 `语音词库`
- 头控适合在姿态稳定、但手不方便时使用

## 常见问题

### 1. 我点了开关，但还是没反应

先回到 `总览` 看 `准备情况`。  
最常见的原因是：

- `辅助功能` 没开
- `麦克风` 没开
- `语音识别` 没开
- 当前没有可用麦克风

### 2. 菜单栏显示正常，但主窗口提示权限没开

先确认你运行的是安装在 `/Applications` 里的 Aether。  
如果还是不对，先退出 Aether 再重新打开，然后回到 `总览` 重新检查权限状态。

### 3. 说话没有出字

先检查：

- `语音输入` 是否开启
- 你是否真的在输入框里
- 麦克风是否选对
- 当前唤起方式是不是 `按住说话`

如果你用的是 `按住说话`，需要一直按住快捷键，松开就会停止。

### 4. 说话能听到，但命令不执行

先检查：

- `语音控制` 是否开启
- 当前是不是更适合输入文字的场景
- 你说的命令能不能在 `语音词库` 或 `应用快捷键` 里找到

### 5. 头控指针没动

先检查：

- 兼容耳机是否连接
- `头控指针` 是否真的开启
- 是否需要重新 `校准`
- `辅助功能` 是否已授权

## 最后建议

对大多数人来说，先把这份指南和 `总览` 页用顺就够了。  
如果仍然没法正常使用，把你遇到的问题、当前页面提示和系统版本一起整理后联系支持。
